# For Dikha ❤

## Customise
1. Open `index.html` and edit the `CONFIG` block at the top (your name, timeline, letter, reasons).
2. Put your photos in the `images/` folder and list them under `photos` in CONFIG (file name + optional caption).

## Publish on GitHub (free)
1. Create a new **public** repository on github.com (e.g. `for-dikha`).
2. Click **Add file → Upload files**, drag in `index.html` and the `images` folder, then **Commit**.
3. Go to **Settings → Pages**. Under *Branch* choose `main` and `/ (root)`, then **Save**.
4. After ~1 minute your link will be `https://YOUR-USERNAME.github.io/for-dikha/` — send it to her!

Tip: keep photos under ~500 KB each so the page loads fast.
